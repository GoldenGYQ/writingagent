THE THROUGH-LINE

Agent 的价值，
不只在生成。

  • 01 把不确定的模型输出放进可观察的工具闭环
  • 02 把知识和权限变成模型必须遵守的边界
  • 03 把修改、证据和执行结果留下可恢复的记录

HOW I THINK / 02

从模型能力，
走到系统责任。

我更关心“出了问题之后能不能解释、审核和恢复”，而不只是一次回答是否看起来正确。

A

Evidence first

让知识拥有来源位置、引用片段和关系上下文；检索返回有界证据，而不是把整个知识库塞进上下文。

B

Changes over overwrite

让 Agent 提交结构化修改，经过确认再生成 Revision；保留 diff、基线、反馈和回退路径。

C

Constraints are product

用 Tool、Policy、Scope、Schema 和人工确认把模型的能力放进可验证的边界里。
